📋 Task Manager API Tester

🚀 Base URL: http://localhost:8001
📌 API доступен по адресу: /tasks и /categories
🔍 Поиск по названию (name), а не по ID

📝 Задачи

📋 GET /tasks (все задачи)

➕ POST /tasks (создать задачу)

✏️ PATCH /tasks?title={название} (обновить по имени)

🗑️ DELETE /tasks?title={название} (удалить по имени)

🏷️ Категории

📋 GET /categories (все категории)

➕ POST /categories (создать категорию)

✏️ PATCH /categories?category_name={название} (переименовать)

🗑️ DELETE /categories?category_name={название} (удалить по имени)
